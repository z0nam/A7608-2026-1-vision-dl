## 0. 큰 그림: 이 레포트가 하나로 꿰는 것

컴퓨터 비전의 세 과제 — **분류(classification), 검출(detection), 분할(segmentation)** — 은 흔히 따로 배우지만, 실제로는 **하나의 척추(backbone CNN)** 를 공유하고 "출력 머리(head)"만 바꿔 끼운 형제들이다. 본 레포트의 일관된 주장은 다음 한 문장이다:

> **좋은 특징 표현(feature representation)을 안정적으로 학습·보존하는 구조적 장치가 분류·검출·분할 모두의 성능을 떠받친다.**

이 장치의 대표가 **skip connection**이며, 분류의 ResNet과 분할의 U-Net이 같은 아이디어를 공유한다. 세 과제의 차이는 "출력의 공간 해상도"가 점점 정밀해지는 것으로 정리된다:

| 과제 | 질문 | 출력 단위 | 공간 정밀도 |
|---|---|---|---|
| 분류 | "이 이미지는 **무엇**인가?" | 이미지당 라벨 1개 | 없음(전역) |
| 검출 | "**무엇**이 **어디에** 몇 개?" | 객체당 박스+라벨 | 박스 수준(거침) |
| 분할 | "**모든 픽셀**이 무엇인가?" | 픽셀당 라벨 | 픽셀 수준(최고) |

## 1. 토대 복습: CNN은 왜 이미지를 잘 다루는가

세 과제를 비교하기 전에, 세 과제가 공유하는 토대인 CNN의 핵심 성질을 정리한다. 이것이 뒤의 모든 설명의 전제다.

**(1) 합성곱(convolution) — 지역성과 가중치 공유.** 완전연결층(FC)은 모든 입력 픽셀을 모든 출력에 연결해 파라미터가 폭발하고, 이미지의 공간 구조를 무시한다. 합성곱은 작은 커널(예: 3×3)을 이미지 전체에 **같은 가중치로 미끄러뜨린다**. 두 가지 이득이 있다 — ① **지역성(locality)**: 이웃 픽셀끼리의 패턴(에지·코너)을 본다. ② **가중치 공유(weight sharing)**: 같은 필터를 전 영역에 재사용하므로 파라미터가 적고, "고양이 귀"가 좌상단에 있든 우하단에 있든 같은 필터가 반응한다(이동 등변성, translation equivariance).

**(2) 계층적 특징(hierarchy).** 층을 쌓으면 **수용 영역(receptive field)** 이 넓어진다. 얕은 층은 에지·텍스처 같은 저수준 패턴을, 깊은 층은 그것들을 조합한 눈·바퀴·얼굴 같은 고수준 의미를 본다. "특징을 사람이 설계"하던 시대를 끝낸 핵심이 바로 이 자동 계층 학습이다.

**(3) 다운샘플링(downsampling) — 왜 해상도를 일부러 줄이는가.** *(메모: 약점 보강 지점)* pooling이나 stride>1 합성곱으로 특징 맵의 H×W를 절반씩 줄인다. 이유는 세 가지다 — ① 수용 영역을 빠르게 넓혀 더 큰 맥락을 보게 하고, ② 연산·메모리를 줄이며, ③ 약간의 위치 변화에 둔감(불변)해져 일반화에 도움을 준다. **다운샘플링의 대가는 위치 정보의 손실**인데, 바로 이 손실을 어떻게 다루느냐가 검출·분할 설계의 핵심 쟁점이 된다(분할의 skip connection이 이 손실을 보충한다).

**(4) 1×1 합성곱 — "공간이 아니라 채널을 섞는다".** *(메모: 약점 보강 지점)* 1×1 커널은 공간적으로는 한 픽셀만 보지만, **채널 방향으로는 모든 채널을 가중합**한다. 용도는 ① **채널 수 조절**(예: 256→64로 줄여 연산량 감소, 또는 늘리기), ② 채널 간 정보를 섞는 작은 MLP 역할, ③ 비선형(ReLU)과 결합해 표현력 추가. ResNet의 bottleneck 블록(1×1로 줄이고 → 3×3 → 1×1로 복원)이 대표 사용처로, 깊은 망의 연산량을 크게 절약한다.

〔제출용 핵심〕 CNN은 지역성·가중치 공유로 이미지의 공간 구조를 효율적으로 학습하며, 다운샘플링으로 맥락을 넓히되 위치 정보를 잃는다. 이 위치 정보 손실의 처리 방식이 분류·검출·분할을 가른다.

## 2. 분류(Classification): AlexNet → ResNet → EfficientNet

분류는 "이미지 전체 → 클래스 1개"다. 출력에 공간 정보가 없어 가장 단순하지만, 여기서 학습된 backbone이 이후 모든 과제의 토대가 되므로 가장 중요하다.

### 2.1 발전의 흐름과 각 모델이 푼 문제

**AlexNet (2012) — "깊은 CNN이 정말 통한다"를 증명.** ImageNet 대회에서 압도적 성능으로 딥러닝 부흥을 열었다. 기여는 모델 구조 자체보다 **학습을 가능하게 한 요소들**이다: ReLU(시그모이드의 기울기 소실 완화, 학습 속도 향상), Dropout(과적합 억제), 데이터 증강, 그리고 GPU 병렬 학습. 한계는 파라미터가 많고(특히 FC층) 구조가 무겁다는 점.

**ResNet (2016) — "깊게 쌓아도 학습되게" 만든 전환점.** 핵심 문제의식은 **열화(degradation)** 다. 직관과 달리, 평범한 망은 층을 더 쌓으면 학습 오차마저 더 커진다(과적합이 아니라 **최적화 자체가 어려워짐**). 너무 깊으면 기울기가 앞쪽 층까지 잘 전달되지 않기 때문이다.

해결책이 **잔차 학습(residual learning)** 이다. 블록이 목표 함수 H(x)를 통째로 학습하는 대신, **잔차 F(x) = H(x) − x** 만 학습하고 출력은 **F(x) + x** 로 만든다. 입력 x를 그대로 더해주는 길이 **skip connection(shortcut)** 이다.

- *왜 쉬워지나*: 만약 어떤 층이 "아무것도 안 하는 게 최선"(항등 함수)이라면, 평범한 망은 여러 비선형 층으로 항등을 흉내 내야 해서 어렵다. 잔차 구조는 F(x)=0으로만 만들면 되니 **항등 함수를 학습하기가 쉽다**. 즉 "깊게 쌓아도 최소한 손해는 안 본다"가 보장된다.
- *왜 기울기가 잘 흐르나*: 역전파 시 +x 경로가 **기울기 고속도로** 역할을 해, 깊은 층의 기울기가 감쇠 없이 앞으로 전달된다.
- 함께 쓰인 **배치 정규화(BatchNorm)** 가 각 층 입력 분포를 안정화해 깊은 망 학습을 보조한다. **bottleneck 블록**(1×1→3×3→1×1)으로 깊이를 늘리면서도 연산량을 통제했다(§1-(4) 참조).

ResNet의 의의는 단순한 성능 향상을 넘어 **이후 검출·분할 모델의 표준 backbone**이 되었다는 데 있다. 본 레포트가 ResNet을 분류 대표로 고른 이유다.

**EfficientNet (2019) — "정확도와 효율을 함께".** 보통 깊이(depth)·너비(width)·입력 해상도(resolution)를 따로따로 키우는데, EfficientNet은 **compound scaling**으로 세 축을 정해진 비율로 **동시에** 키운다. 적은 연산·파라미터로 높은 정확도를 달성해, "무조건 크게"가 아니라 "효율적으로 크게"라는 현대적 설계 방향을 대표한다. 단, 설계 원리가 다소 추상적이라 직관적 설명이 어렵다.

### 2.2 입력/출력과 평가지표

- **입력**: RGB 이미지 1장. **출력**: 클래스 확률 벡터(예: ImageNet 1000차원), argmax가 예측 클래스.
- **평가지표**: **Top-1 Accuracy**(최상위 예측이 정답인 비율), **Top-5 Accuracy**(상위 5개 안에 정답 포함 비율 — 클래스가 많고 비슷할 때의 관대한 지표).
- **공개 성능(참고)**: ResNet-50, ImageNet 검증셋 Top-1 ≈ 76%, Top-5 ≈ 93%.

### 2.3 실험: 전이학습 기반 소규모 분류 (ch06)

ImageNet 사전학습 backbone을 소규모 이진 분류 데이터셋에 **전이학습(transfer learning)** 으로 미세조정했다. 짧은 학습(10 epoch 내외)에서 검증 정확도 약 **58%** 에 머물렀다(Top-5는 클래스가 2개뿐이라 100%).

**분석**: 절반 남짓이면 사실상 잘 학습되지 않은 것이다. 원인은 ① 데이터셋이 작고, ② 학습 epoch이 짧아 backbone이 새 도메인에 충분히 적응하지 못했으며, ③ 학습률·해동(freeze/unfreeze) 설정의 영향으로 보인다. 이 결과의 교훈은 분명하다 — **사전학습이 만능은 아니다. 전이학습도 충분한 데이터·학습·튜닝이 있어야 위력을 발휘한다.** (대표 성능 비교에는 공개 ImageNet 수치를 사용한다.)

〔제출용 핵심〕 ResNet은 잔차 학습(F(x)+x)과 skip connection으로 "깊게 쌓아도 최적화되는" 문제를 풀어 이후 검출·분할의 표준 backbone이 되었다. 전이학습 실험(~58%)은 사전학습이 데이터·학습량에 의존함을 보였다.

## 3. 검출(Detection): R-CNN 계열 → Faster R-CNN

검출은 "이미지 → **객체별** (위치 박스 + 클래스 + 신뢰도) 목록"이다. 분류와의 결정적 차이 두 가지: ① **출력 개수가 가변적**이다(객체가 0개일 수도, 수십 개일 수도). ② **위치(좌표)를 회귀**해야 한다. 분류가 잃어버린 위치 정보를 다시 살려내야 하는 첫 과제다.

### 3.1 발전의 흐름: 왜 "Faster"인가

**R-CNN (2014)**: Selective Search로 후보 영역 ~2000개를 뽑아, **각각을 잘라 CNN에 따로 통과**시켜 분류. 정확하지만 한 이미지에 CNN을 2000번 돌려 끔찍하게 느리다.

**Fast R-CNN (2015)**: 이미지 전체를 CNN에 **한 번만** 통과시켜 특징 맵을 얻고, 후보 영역을 그 특징 맵 위에서 **RoI pooling**으로 잘라 쓴다. CNN 중복 계산 제거로 크게 빨라졌다. 하지만 후보 영역 생성(Selective Search)은 여전히 CNN 바깥의 느린 단계.

**Faster R-CNN (2015)**: 후보 영역 생성마저 신경망 안으로 넣은 **RPN(Region Proposal Network)** 을 도입. 이제 제안~분류가 모두 GPU에서 end-to-end로 돌아 실시간에 가까워졌다. 이름의 "Faster"가 여기서 온다.

### 3.2 핵심 구성요소 (자세히)

**① Backbone (예: ResNet + FPN)**: 입력 이미지 → 특징 맵. FPN(Feature Pyramid Network)은 여러 해상도의 특징을 합쳐 큰 객체·작은 객체를 모두 잘 잡게 한다.

**② RPN — 객체가 있을 법한 곳 제안.** 특징 맵의 각 위치마다 여러 크기·비율의 **앵커(anchor) 박스**를 미리 깔아두고, 각 앵커에 대해 (a) "객체일 확률(objectness)"과 (b) 박스 미세조정값을 예측한다. 점수 높은 후보만 남긴다. *핵심 아이디어*: "박스를 0에서 만들지 말고, 촘촘히 깔아둔 후보를 **골라내고 다듬는다**."

**③ RoI Pooling/Align — 가변 크기 영역 → 고정 크기 특징.** 후보 영역은 크기가 제각각인데 뒤의 FC층은 고정 크기를 요구한다. RoI pooling이 어떤 크기의 영역이든 예: 7×7로 맞춘다(RoI Align은 정렬 오차를 줄인 개선판).

**④ Head — 최종 분류 + 박스 회귀.** 각 RoI를 클래스로 분류하고 박스를 한 번 더 정밀하게 조정한다.

**⑤ NMS(Non-Maximum Suppression) — 중복 제거.** 한 객체에 박스가 여러 개 겹쳐 나오므로, 가장 점수 높은 박스만 남기고 그것과 많이 겹치는(IoU 큰) 나머지를 지운다.

**2단계(two-stage) vs 1단계(one-stage)**: Faster R-CNN은 "제안 → 분류"의 2단계라 정확하지만 무겁다. YOLO·SSD 같은 1단계는 제안 단계 없이 한 번에 박스+클래스를 예측해 훨씬 빠르지만 전통적으로 약간 덜 정확했다. **정확도-속도 트레이드오프**의 양극단이다.

### 3.3 평가지표: IoU와 mAP (자세히)

- **IoU(Intersection over Union)**: 예측 박스와 정답 박스의 (교집합 넓이)/(합집합 넓이). 1이면 완전 일치. 보통 **IoU ≥ 0.5** 면 "맞게 위치를 잡았다"고 본다.
- **Precision/Recall**: 검출을 IoU 기준으로 정답(TP)·오검출(FP)·놓침(FN)으로 나눈다. **Precision = TP/(TP+FP)**("내가 찾은 것 중 진짜 비율"), **Recall = TP/(TP+FN)**("실제 있는 것 중 찾은 비율"). 점수 임계값을 낮추면 많이 검출해 Recall↑ Precision↓, 높이면 반대.
- **AP/mAP**: 임계값을 바꿔가며 그린 Precision-Recall 곡선의 아래 면적이 **AP**, 모든 클래스 평균이 **mAP**. 검출의 표준 단일 지표다.

### 3.4 실험: PennFudanPed 보행자 검출 (zero-shot COCO)

**설정**: COCO로 사전학습된 `fasterrcnn_resnet50_fpn_v2` 를 **추가 학습 없이** 그대로 사용. COCO에 이미 'person' 클래스가 있으므로(보행자=사람), 모델 예측 중 **person(COCO label 1)** 만 골라 PennFudanPed(170장, 정답 보행자 박스 423개)와 비교했다(IoU≥0.5 매칭).

> *왜 zero-shot인가*: 원래 노트북은 분류 헤드를 새것으로 교체 후 fine-tuning하려 했으나, 학습이 수행되지 않아(또는 과한 학습률로 발산해) 모든 지표가 0이었다. 헤드를 교체하면 COCO가 배운 분류 능력이 사라지기 때문이다. 헤드를 **건드리지 않고** 추론만 하면 사전학습 능력을 그대로 활용할 수 있다.

| ≥ 0.7 | 422 | 263 | 1 | 0.616 | **0.998** | 0.762 | **0.895** |

**분석 (자세히)**:
- **Recall 0.998**: 정답 423개 중 422개를 잡았다(놓침 1개). 학습을 한 번도 안 했는데 거의 다 검출 — COCO에 사람 데이터가 풍부해 **backbone+head 전체가 보행자 도메인으로 잘 전이**됨을 보여준다. §2의 분류 전이학습(~58%)이 부진했던 것과 대비된다. 차이는 "도메인 일치도": 보행자는 COCO의 person과 거의 같은 객체지만, ch06 이진 분류는 새 도메인이라 적응이 필요했다.
- **평균 IoU 0.895**: 맞게 잡은 박스들이 정답과 매우 정확히 겹친다. 위치 회귀 품질이 높다.
- **Precision 0.55~0.62 (낮음)**: FP가 많기 때문. 원인은 (a) PennFudan 마스크에 라벨링되지 **않은** 배경 인물까지 모델이 정직하게 검출, (b) 한 사람에 박스가 중복으로 잡히는 경우. 즉 "모델이 틀렸다기보다 데이터 라벨이 일부 사람을 빠뜨린" 성격의 FP가 섞여 있다.
- **임계값 효과**: 0.5→0.7로 올리면 자신 없는 검출이 걸러져 FP 344→263, Precision 0.551→0.616, F1 0.710→0.762로 개선(Recall은 0.998 유지). **임계값이 Precision–Recall 트레이드오프를 조절하는 손잡이**임을 실측으로 확인.

〔제출용 핵심〕 Faster R-CNN은 RPN으로 영역 제안을 신경망에 통합한 2단계 검출이다. COCO zero-shot만으로 Recall 0.998·IoU 0.895를 얻어 backbone 전이의 강력함을 보였고, 임계값(0.5→0.7)으로 F1이 0.71→0.76 개선되어 정밀도-재현율 트레이드오프를 확인했다.

## 4. 분할(Segmentation): FCN → U-Net

분할은 "이미지 → **픽셀별** 라벨 맵"으로, 출력이 입력과 같은 해상도다. 검출이 위치를 박스로 거칠게 잡았다면, 분할은 **모든 픽셀**을 분류해 가장 정밀한 위치 정보를 낸다.

### 4.1 핵심 난제와 해결: 다운샘플로 잃은 해상도를 어떻게 되살리나

분류 backbone은 다운샘플(§1-(3))로 H×W를 16~32배 줄여 의미 정보를 농축한다. 그런데 분할은 **원해상도 출력**이 필요하다. 어떻게 복원할까?

**FCN (2015)**: 분류망의 FC층을 1×1 합성곱으로 바꿔 어떤 크기 입력도 받게 하고(fully convolutional), 줄어든 특징 맵을 **업샘플링(upsampling)** 으로 키워 픽셀 라벨을 낸다. 분할 딥러닝의 출발점.

**업샘플링이란** *(메모: downsample의 짝)*: 다운샘플의 반대로 해상도를 **키우는** 연산. 방식은 ① 단순 보간(최근접·이중선형), ② **전치 합성곱(transposed convolution, "deconv")** — 학습 가능한 가중치로 키우며 디테일을 복원. 디코더가 이걸로 단계별로 H×W를 두 배씩 늘려 원해상도까지 복원한다.

**U-Net (2015) — 인코더-디코더 + skip connection.**
- **인코더(수축 경로)**: conv→conv→pool 반복. 해상도↓, 채널↑, 의미 정보 농축. (= 분류 backbone)
- **디코더(확장 경로)**: 업샘플→conv 반복. 해상도↑, 채널↓, 위치 정보 복원.
- **skip connection (핵심)**: 같은 단계의 **인코더 특징을 디코더로 직접 연결**해 합친다.

*왜 skip이 결정적인가*: 인코더 깊은 곳은 "무엇인지(의미)"는 알지만 다운샘플로 **"정확히 어디인지(경계)"** 를 잃었다. 반면 인코더 얕은 곳은 위치·경계는 또렷하나 의미가 약하다. skip은 **얕은 층의 또렷한 경계 정보**를 디코더로 가져와, 깊은 층의 의미와 결합한다. 그래서 U-Net은 객체의 **윤곽을 픽셀 단위로 날카롭게** 복원한다. (ResNet의 skip이 "기울기 보존"이라면, U-Net의 skip은 "공간 정보 보존" — 같은 더하기/잇기 아이디어의 다른 활용이다.)

### 4.2 손실 함수와 평가지표

- **손실**: 픽셀별 다중 클래스 분류이므로 **CrossEntropy**가 기본. 전경이 작아 클래스 불균형이 심하면 **Dice loss**(겹침을 직접 최적화)를 함께 쓰기도 한다.
- **평가지표**: **mIoU(mean IoU)** — 클래스별 (예측∩정답)/(예측∪정답) 픽셀 비율을 구해 평균. 분할의 표준 지표. (+ 픽셀 정확도, 단 불균형에 약함.)

### 4.3 실험: Oxford-IIIT Pet 분할 (U-Net)

**설정**: 원본 U-Net(Ronneberger 2015) 구조 + ImageNet 사전학습 **VGG16 인코더**(TernausNet 방식). Oxford-IIIT Pet(학습 3,680 / 테스트 3,669장), **3클래스**(전경=반려동물 / 배경 / 경계). 손실 CrossEntropy, 최적화 Adam.

| 단계 | 손실 | mIoU |
|---|---|---|
| 학습 (1 epoch, 100배치 평균) | 0.8625 | 0.465 |
| **테스트** | 0.4734 | **0.691 (69.1%)** |

학습 중 배치별 IoU 추이: 0.120 → 0.217 → 0.325 → 0.407 → 0.465 (빠른 상승).

**분석 (자세히)**:
- **단 1 epoch에 테스트 mIoU 69.1%**: 사전학습 인코더 + skip connection 덕에 매우 빠르게 수렴. 만약 처음부터 학습했다면 1 epoch로는 어림없다 — **전이학습의 위력**이 분할에서도 확인된다.
- **테스트(0.691) > 학습 평균(0.465)** 인 이유: 학습 평균은 IoU가 0.12였던 **초기 저성능 배치까지 포함**한 평균이라 낮게 나온다. 테스트는 학습이 끝난 모델로 한 번에 평가하므로 더 높다(과적합이 아니라 측정 구간의 차이).
- **'경계' 클래스가 약점**: 전경/배경은 잘 나뉘지만 경계 픽셀은 얇고 모호해 IoU가 낮고, 이것이 전체 mIoU를 끌어내린다. 이는 §4.1에서 skip connection이 보강하려는 바로 그 어려움(경계 복원)과 정확히 맞닿는다 — 더 많은 epoch이나 경계 가중 손실로 개선 여지가 있다.

〔제출용 핵심〕 U-Net은 인코더-디코더에 skip connection을 더해 다운샘플로 잃은 경계 정보를 복원한다. 사전학습 인코더로 1 epoch만에 테스트 mIoU 69.1%를 얻었고, 얇고 모호한 '경계' 클래스가 주된 오차원이었다.

## 5. 동일 관점 비교표와 통합 분석

### 5.1 동일 관점 비교표

| 관점 | 분류 (ResNet) | 검출 (Faster R-CNN) | 분할 (U-Net) |
|---|---|---|---|
| **입력 형태** | RGB 이미지 1장 | RGB 이미지 1장 | RGB 이미지 1장 |
| **출력 형태** | 클래스 확률 벡터(이미지당 1개) | 객체별 (박스+클래스+점수) 목록(가변 개수) | 입력과 동일 해상도의 픽셀별 라벨 맵 |
| **위치 정보** | 없음 | 박스 수준(거침) | 픽셀 수준(최고) |
| **핵심 구조** | residual block + skip connection | backbone + RPN + RoI head (2단계) | 인코더-디코더 + skip connection |
| **장점** | 단순·안정적 학습, backbone 재사용 | 다중 객체 위치 검출, 높은 정확도 | 픽셀 단위 정밀 경계, 적은 데이터에 강건 |
| **단점** | 위치 정보 없음 | 2단계라 무겁고 느림 | 출력 해상도 커 연산·메모리 비용 큼 |
| **평가지표** | Top-1 / Top-5 Accuracy | mAP (+ Precision/Recall/F1, IoU) | mIoU, 픽셀 정확도 |
| **본 실험 결과** | 전이학습 검증 ~58% (공개 ImageNet Top-1 ~76%) | Recall 0.998, F1 0.762, IoU 0.895 (zero-shot) | 테스트 mIoU 69.1% (1 epoch) |

### 5.2 통합 분석: 세 과제를 관통하는 세 가지 통찰

**① 하나의 backbone, 갈아 끼우는 head.** 세 모델 모두 동일한 CNN 특징 추출기에 기반한다. ResNet 같은 분류 backbone이 검출(Faster R-CNN의 backbone)과 분할(U-Net 인코더)에 그대로 재사용된다. 차이는 출력 head뿐이다 — 분류는 전역 풀링+FC, 검출은 RPN+RoI head, 분할은 업샘플 디코더. **"표현 학습은 공유, 과제는 head로 분기"** 가 현대 비전의 설계 문법이다.

**② 평가지표는 모두 한 뿌리(혼동행렬)에서 갈라진다.** Accuracy, Precision/Recall/F1, IoU·mAP·mIoU는 모두 TP/FP/FN의 조합이다. 단위만 다르다 — 분류는 **이미지** 단위, 검출은 **박스**(IoU≥0.5로 정답 판정) 단위, 분할은 **픽셀** 단위로 같은 셈을 한다. 지표를 따로 외울 게 아니라 "무엇을 한 단위로 세느냐"의 차이로 이해하면 된다.

**③ 다운샘플이 만든 위치 정보 손실, 그리고 그 보충.** §1에서 다운샘플은 맥락을 넓히는 대가로 위치를 잃는다고 했다. 세 과제는 이 손실을 각자 다루는 방식이다 — 분류는 위치가 필요 없어 **무시**, 검출은 앵커·RoI·박스 회귀로 위치를 **재구성**, 분할은 skip connection으로 얕은 층의 위치 정보를 **되살린다**. 과제가 정밀해질수록 "잃어버린 위치를 어떻게 되찾느냐"가 설계의 본질이 된다.

### 5.3 실험들이 함께 말해 주는 것: 전이의 도메인 의존성

세 실험을 한자리에 놓으면 **전이학습의 성패는 도메인 일치도에 달렸다**는 일관된 메시지가 보인다. 검출(보행자=COCO person, 거의 동일 도메인)은 zero-shot으로도 Recall 0.998. 분할(Pet, 새 객체지만 사전학습 인코더 사용)은 1 epoch에 69.1%. 분류(ch06 이진, 새 도메인+짧은 학습)는 58%에 그쳤다. **사전학습된 표현이 강력할수록, 그리고 목표가 사전학습 도메인에 가까울수록, 적은 학습으로 큰 성능**을 얻는다.

## 6. 결론 및 개인 의견

CNN 기반 비전은 "이미지 → 라벨 1개"의 분류에서 출발해, 위치를 함께 묻는 검출, 모든 픽셀을 분류하는 분할로 **출력의 정밀도를 높여** 왔다. 그러나 이들은 별개가 아니라, 같은 특징 표현 위에 과제별 head를 얹은 형제다. 본 실험들이 이를 구체적으로 뒷받침한다 — 검출 zero-shot의 Recall 0.998·IoU 0.895, 분할 1 epoch의 mIoU 69.1%는 모두 **잘 학습된 backbone 표현의 전이력**에서 나왔다.

개인적으로 한 학기를 관통하는 가장 중요한 아이디어는 **skip connection**이라고 생각한다. ResNet에서는 기울기를 보존해 "깊게 쌓는 것"을, U-Net에서는 공간 정보를 보존해 "정밀하게 복원하는 것"을 가능케 했다. 표면적으로는 단순한 "더하기/잇기"지만, **좋은 정보를 손실 없이 흘려보내는 통로**라는 본질은 같다. 검출 역시 그 위에 선 잘 학습된 표현에 의존한다. 결국 비전 성능의 핵심은 "더 화려한 head"가 아니라 "**좋은 표현을 안정적으로 학습·보존하는 구조**"임을 세 과제 모두가 보여준다. 앞으로의 연구는 이 토대 위에 Transformer 결합(ViT·DETR), 경량화, 실제 배치 효율을 더하는 방향으로 나아갈 것이다.

| 용어 | 한 줄 설명 |
|---|---|
| 수용 영역(receptive field) | 출력 한 점이 입력에서 "보는" 영역. 층이 깊을수록 넓어짐 |
| 다운샘플링 | pool/stride로 해상도↓ — 맥락↑·연산↓, 위치 정보↓ |
| 업샘플링 / 전치 합성곱 | 해상도↑ 복원. 학습 가능한 deconv로 디테일 회복 |
| 1×1 합성곱 | 공간이 아닌 채널을 섞음 — 채널 수 조절·연산 절감 |
| skip connection | 입력/얕은 층 정보를 뒤로 직접 연결 — 기울기·공간정보 보존 |
| residual learning | H(x) 대신 잔차 F(x)=H(x)−x를 학습, 출력 F(x)+x |
| BatchNorm | 층 입력 분포 정규화로 깊은 망 학습 안정화 |
| 앵커(anchor) | 미리 깔아둔 다양한 크기·비율의 후보 박스 |
| RPN | 객체가 있을 법한 영역을 제안하는 신경망(Faster R-CNN) |
| RoI Pooling/Align | 가변 크기 영역을 고정 크기 특징으로 변환 |
| NMS | 겹치는 중복 박스 제거(점수 최고만 남김) |
| IoU | (교집합)/(합집합) — 겹침 정도, 검출·분할 공통 |
| Precision / Recall | 찾은 것 중 맞은 비율 / 실제 중 찾은 비율 |
| mAP | 클래스별 PR곡선 면적(AP)의 평균 — 검출 표준 지표 |
| mIoU | 클래스별 IoU의 평균 — 분할 표준 지표 |
| 전이학습 | 사전학습 가중치를 새 과제에 미세조정 |
| zero-shot | 추가 학습 없이 사전학습 모델을 바로 사용 |
