# CH3 발표 작업 공간

이 폴더는 Chapter 3 발표 준비를 위한 작업 공간이다. 우선순위는 다음과 같다.

1. 3.2 비지도학습 설명에 필요한 핵심 그림을 정리한다.
2. 실습과 직접 연결되는 항목은 가능한 한 코드 출력으로 재현한다.
3. 최종 산출물은 `slides/` 아래 발표 자료로 정리한다.

## 작업 원칙

- 세미나 참여자와 함께 보는 기준 파일은 `slides/python_3장_seminar.ipynb`이다.
- 발표용 노트북은 `3.2 비지도학습`부터 시작하도록 정리한다.
- 원본 교재 실습 노트북(`python_3장.ipynb`, `colab_3장.ipynb`)은 그대로 보관한다.
- `code/` 아래 파일은 발표 그림 재생성이나 빠른 실행을 위한 보조 스크립트로만 사용한다.
- 노트북 내용을 대체하는 별도 강의용 코드 구조로 키우지 않는다.

## 폴더 구조

- `slides/figures/`: 슬라이드에서 직접 사용하는 그림
- `slides/`: 발표 슬라이드 초안
- `code/`: 발표 중 보여줄 실습 재현 코드
- `tools/`: 보조 처리 스크립트
- `context.md`: 다른 세션으로 넘길 때 필요한 작업 맥락
